# Proses-Belajar_project-GAS_AG-Tasya
sebuah proses belajar berbasis membuat aplikasi html dengan sistem di simpan di Google Appscript untuk membantu kerja Ahli Gizi mengkalkulasi nilai gizi  menu makanan MBG dan merancang RAB

tujuan utama dari project ini adalah mengenal coding dengan
  - pemanfaatan AI Gemini dalam penyusunan code "Kode,gs", "Index.html" dan file file pendukung lainnya
  - tujuannya bukan mengkoding sendiri, tapi mengamati terlebih dahulu bagaimana struktur fungsi kode dibentuk untuk tiap kebutuhan diikut penyempurnaan komunikasi efektif dengan AI seperti Gemini
  - disini juga akhirnya commit menggunakan github sebagai perpustakaan untuk elbih mudah memantau update kode yang di buat

dari proses ini harapannya
  - memahami pengaplikasian kode
  - memahami pengaplikasian AI
  - memahami alur proses kode
  - mengembangkan pola pikir
  - memahami secara menyeluruh dan menjadi batu loncatam untuk pemantapan keilmuan coding saya
